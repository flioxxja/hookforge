# ⚒️ HookForge — AI Hook & Idea Studio for Creators

**Live demo:** https://flioxxja.github.io/hookforge/
**Devpost:** https://devpost.com/software/hookforge-ai-hook-idea-studio-for-creators

Forge scroll-stopping hooks for TikTok, Reels and Shorts — with a virality score, a plain-English "why it works", a ready-to-film 30-second script, caption and hashtags. Free, no sign-up, works offline after load.

## Features
- **8 niches** (AI & Tech, Money, Fitness, Food, Study, Beauty, Gaming, Travel) × platform × goal × 4 tones
- **Virality scoring model**: numbers, questions, pattern-interrupt words, direct viewer address, 35–85 char sweet spot, curiosity gaps
- **30-second script builder**: hook → value → CTA + best posting window
- **Caption + hashtags** generated per niche/platform
- **Favorites & counters** saved in localStorage, **Download .txt** export, **Surprise me** random combo
- Winter snowfall canvas, animated score bars, fully responsive

## Built with
Vanilla HTML/CSS/JavaScript (single file), Canvas API, localStorage. No build step, no backend.

Built for the Creators AI Winter Challenge (Devpost). AI-assisted development disclosed on the Devpost page.
