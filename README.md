# HookForge — AI Hook & Idea Studio for Creators

Generate scroll-stopping hooks, a 30-second script, a caption and hashtags for TikTok, Instagram Reels and YouTube Shorts — in under a minute, free, with no sign-up.

**Live demo:** https://flioxxja.github.io/hookforge/

## What it does
- Pick niche (AI & Tech, Money, Fitness, Food, Study, Beauty), platform, goal and tone
- Forges 5 hooks from proven short-form patterns, each with a **virality score** (curiosity words, numbers, questions, length sweet-spot, emotional triggers) and a plain-English "why it works"
- Builds a 30-second script (hook → value → CTA) from the best hook, plus a suggested posting window
- Generates a ready-to-paste caption with niche hashtags
- Copy buttons everywhere; favorites and counters saved locally (localStorage)

## How to run
Open `index.html` in any browser, or visit the live demo. No build step, no backend, no API keys.

## Tech
Vanilla HTML/CSS/JS in a single file + Canvas snow effect. Deployed on GitHub Pages.
